# KenzieBurguer 2.0 — Recovery checkpoint (2026-10-12)

## Scope
This branch preserves the UI, fixes broken session-loading and unauthenticated redirect, cart clear-all, login form submit, product currency display and implements live product search.

## Disclosed guest demonstration
Click **Acessar demonstração** on the login page to open a **fictitious** 6-item local catalog with illustrative icons and prices. Search, add products to cart, remove individual products, clear the cart, view the total and log out. No payments, orders, server accounts or real product inventory. Guest session is stored in this browser only.

## Real backend dependency
The legacy URL `https://hamburgueria-kenzie-v2.herokuapp.com` remains an unverified default. Set `VITE_API_BASE_URL` to a verified compatible API:
- `POST /users`
- `POST /login` returning `{user,accessToken}`
- `GET /users/:id` bearer profile
- `GET /products` expected `[{id,name,category,price,img}]`.

The API needs CORS compatible with the deployed Vercel domain. Real signup/login/product backend flows have **not** been verified.
